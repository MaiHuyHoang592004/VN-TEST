# Accessibility contract

The measured floor lives in `readme.md` §7 (contrast ratios, the cream-on-sky
exception, the navy-500 text floor, the opacity ban). This file is the
**per-component checklist** an AI import must satisfy — role, keyboard, focus,
and labelling — gathered in one place so nothing is missed screen by screen.

## Global (every screen)

- **Focus ring is never removed.** 3px Action Blue at 2px offset
  (`--shadow-focus` on fields, `outline` elsewhere) — on every surface, incl.
  sky. Do not `outline:none` without an equal replacement.
- **`prefers-reduced-motion`** disables every named keyframe (spin, pulse,
  shimmer, fades, slides, rise, ring). No animation may be essential to meaning.
- **Text ink floor:** never lighter than `navy-500` on cream/white/pale-sky.
  `navy-400`/`navy-300` are non-text only (icons, borders, dots, disabled).
- **Never de-emphasise small text with `opacity`** — it silently drops verified
  contrast. Use size/weight/tracking.
- **Touch targets ≥ 44px** below 768px.
- **Status is colour + a text label, always** — colour is never the only signal.
- One document `<title>` per screen; page identity also available as the active
  nav pill (navy on cream, 11.5:1) — never only as cream-on-sky hero type.

## Per component

| Component | Required a11y |
|---|---|
| `Button` | Real `<button>`; `disabled` reflects a true gate; loading state keeps an accessible name. |
| `IconButton` | **`label` is required** (visually-hidden accessible name) — enforced by the prop. 44px min below md. |
| `StatusBadge` | Renders the label as text (not colour alone); 11–12px bold pairs are contrast-verified ≥4.5:1. |
| `Input`/`Select`/`SearchField` | Associated `<label>` (or `aria-label`); error text tied via `aria-describedby`; focus ring intact. `Select` is keyboard-operable (native or ARIA listbox with arrow keys). |
| `SegmentedControl` | `role="radiogroup"`/`tablist` per use; arrow-key movement; selected state not colour-only (fill + `aria-checked`/`aria-selected`). |
| `TabBar` | `role="tablist"`, `aria-selected`, arrow-key nav, `aria-controls` to the panel. |
| `DataTable` | Real `<table>` semantics (`<th scope>`); sortable headers are buttons with `aria-sort`; row actions reachable by keyboard. |
| `Pagination` | `<nav aria-label>`; current page `aria-current="page"`; prev/next disabled at ends. |
| `Modal`/`Drawer` | `role="dialog" aria-modal`, focus trap, focus returns to opener on close, `Esc` closes, scrim click closes; labelled by its title. |
| `CommandPalette` | `role="dialog"`; the list is a `listbox`/`option` with arrow-key + Enter; ⌘K toggles; `Esc` closes; visible `CommandTrigger` affordance. |
| `Popover`/`DateRangeField` | Trigger has `aria-expanded`/`aria-haspopup`; focus moves into the popover; `Esc` returns focus to trigger. |
| `Toast`/`ToastStack` | `role="status"` (success) / `role="alert"` (critical), `aria-live` polite/assertive to match; auto-dismiss never removes an error the user hasn't seen. |
| `EmptyState`/`LoadingState` | `LoadingState` announces busy (`aria-busy`/`role="status"`); `EmptyState` is real headable text, not an image. |
| `Skeleton` | Decorative — `aria-hidden`; the region it fills carries `aria-busy` on its container. |
| `TicketConversation`/`SupportPanel` | Message list is a labelled log; the selected-item left edge is a state, mirrored with `aria-current`/`aria-selected` (not colour alone). |
| `GwpMark` | `role="img"` + accessible name "GoodWoodPrint"; logotype is exempt from 1.4.3 contrast. |
| `WoodRings`/`CraftCut` | Decorative — `aria-hidden`, never carry meaning or text. |

## Verify per screen (add to the definition of done)

- [ ] Tab through the whole screen: every interactive element is reachable and shows a focus ring.
- [ ] Every icon-only control has an accessible name.
- [ ] Colour removed (grayscale test): status, selection and required-field state still read.
- [ ] `prefers-reduced-motion: reduce` stills all motion.
- [ ] Dialogs trap focus and restore it on close.
