# Copy & i18n

The app is **bilingual by surface, not fully localized**. There is no i18n
framework in the source — strings are literal. This table tells an AI import
which language each surface's chrome is in, and keeps Vietnamese **data values**
(status, ticket reasons) from being "helpfully" translated.

## The rule

- **UI chrome** (nav, buttons, labels, headings) follows the surface:
  - **Seller app + Marketing + Catalog + Auth/Errors → English.** (Voice: warm
    competent craftsperson — see `readme.md` §3.)
  - **Internal warehouse / fulfillment ops → Vietnamese**, because the real app
    labels them so (`Kiểm tra đơn`, `QC đóng gói`).
- **Data values are never translated.** Order statuses (`ORDER_STATUS`), ticket
  reasons (`TICKET_REASON`), roles — render the enum string exactly, in whatever
  language it is stored, on every surface. A Vietnamese ticket reason stays
  Vietnamese even in an English screen.
- **Typeface caveat:** Baloo 2 does **not** fully cover Vietnamese diacritics;
  for Vietnamese display strings use **Nunito Sans bold**, not Baloo 2
  (`readme.md` §2). IBM Plex Mono and Nunito Sans both cover VN.

## Fulfillment-ops on-screen warnings (VN, verbatim — source FE copy)

These are physical-production instructions embedded in the FE, not data; keep
them Vietnamese (`FulfillmentOpsPage.jsx`, UBR-022/023):
- `⚠️ ĐƠN ĐÃ SẢN XUẤT` — order already produced (blocking confirm, check mode).
- `⚠️ ĐƠN ĐANG SẢN XUẤT` — order currently in production.
- `Kiểm tra film dư đã in chưa trước khi làm tiếp` — check for excess printed film before continuing.
- `Không thể chép tự động; hãy chọn và copy mã.` — clipboard-blocked fallback.

## English enums that carry a display name (source `metadata.ts`)

Use the `name`, key on the `value`:
- **SHIPPING_TYPE:** `customer` → "Ship by Platform" · `op` → "Ship by OP".
- **USER_ROLE:** admin→Admin · customer→Customer · warehouse→Warehouse ·
  warehouse_external→Warehouse External · warehouse_admin→Warehouse Admin ·
  supporter→Supporter · designer→Designer.
- **TICKET_STATUS:** open→Open · in_progress→In Progress · closed→Closed.
- **TICKET_PRIORITY:** low→Low · medium→Medium · high→High · critical→Critical.

## For AI import

If the target introduces a real i18n framework, key it on the enum `value` and
seed both languages from this file. Until then, match the source: English
chrome on customer-facing surfaces, Vietnamese chrome on internal warehouse
surfaces, and **enum values verbatim everywhere**.
