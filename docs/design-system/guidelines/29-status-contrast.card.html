Why 4.5 and not 3. A badge label sets at 11–12px bold. Bold only counts as large text at ≥18.66px, so status labels are small text and the 4.5:1 threshold applies. MetricCard's wash tiles reuse the same pairs, so a change to one -fg or -bg moves both — re-check the pair before touching either.
Everything else. Status is colour plus a label, never colour alone. Focus is a 3px Action Blue ring at 2px offset and is never removed on any surface. prefers-reduced-motion disables all animation. Touch targets ≥44px below 768px. Every IconButton requires a label.
