# screenshots/reference — ảnh reference cho Claude Code

PNG chụp từ `ui_kits/**/*.html` (viewport desktop, trạng thái mặc định; file có
tiền tố `01-`/`02-` là primary + trạng thái phụ như row expand / drawer mở).
Claude Code không render được HTML — dùng ảnh này làm visual target khi port,
đối chiếu theo quy trình `VERIFY.md`.

Lưu ý: ảnh là snapshot một thời điểm; nguồn truth vẫn là file HTML + tokens.
Khi screen trong `ui_kits/` đổi, chụp lại ảnh tương ứng (mở file → screenshot
1440px). Cấu trúc: `seller/` · `admin/` · `warehouse/` · `system/` · `marketing/`.
