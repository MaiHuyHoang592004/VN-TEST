DESIGN SYSTEM · v1.0 · DARK-NEON

Docs Kit. A drop-in style system for internal docs.

Vercel-style: pure black, neon accents (blue → purple → pink), interactive scannable layouts. Copy any component below into a new HTML file. The whole :root block + every component class is in this one file. Designed so AI agents (or you) can build new docs in minutes.

§ 08 · vanilla · no dependencies

Progress bar

Fills the fixed top bar based on scroll position.

JS 
const progress = document.getElementById('progress');
window.addEventListener('scroll', () => {
  const h = document.documentElement;
  const pct = (h.scrollTop / (h.scrollHeight - h.clientHeight)) * 100;
  progress.style.width = pct + '%';
}, { passive: true });

Tabs

Auto-binds any .tabs group. Tabpanels must be the following siblings of the tabs group.

JS 
document.querySelectorAll('.tabs').forEach(group => {
  const buttons = group.querySelectorAll('button');
  buttons.forEach(btn => {
    btn.addEventListener('click', () => {
      const id = btn.dataset.tab;
      const panels = [];
      let sib = group.nextElementSibling;
      while (sib && sib.classList.contains('tabpanel')) {
        panels.push(sib);
        sib = sib.nextElementSibling;
      }
      buttons.forEach(b => b.classList.remove('active'));
      panels.forEach(p => p.classList.remove('active'));
      btn.classList.add('active');
      const panel = document.getElementById(id);
      if (panel) panel.classList.add('active');
    });
  });
});

Day checkbox · localStorage persistence

Each .day needs a unique data-id. Survives reload.

JS 
const KEY = 'mydoc_checks';
const saved = JSON.parse(localStorage.getItem(KEY) || '{}');
document.querySelectorAll('.day').forEach(day => {
  const id = day.dataset.id;
  const cb = day.querySelector('input[type=checkbox]');
  if (saved[id]) { cb.checked = true; day.classList.add('done'); }
  cb.addEventListener('change', () => {
    saved[id] = cb.checked;
    localStorage.setItem(KEY, JSON.stringify(saved));
    day.classList.toggle('done', cb.checked);
  });
});

Live T-minus countdown

Updates a hero tile + the nav status. Refreshes every minute.

JS 
function updateTminus() {
  const target = new Date('2026-05-31T09:00:00');
  const now = new Date();
  const diff = target - now;
  const tile = document.getElementById('tminus');
  if (!tile) return;
  if (diff <= 0) { tile.textContent = 'LIVE'; return; }
  const d = Math.floor(diff / (1000*60*60*24));
  const h = Math.floor((diff / (1000*60*60)) % 24);
  tile.textContent = 'T-' + d + 'd ' + h + 'h';
}
updateTminus();
setInterval(updateTminus, 60_000);

Smooth-scroll anchor nav

Offsets for the 64px sticky nav so headings don't get clipped.

JS 
document.querySelectorAll('nav.top a').forEach(a => {
  a.addEventListener('click', e => {
    const href = a.getAttribute('href');
    if (href && href.startsWith('#')) {
      e.preventDefault();
      const el = document.querySelector(href);
      if (el) {
        const top = el.getBoundingClientRect().top + window.scrollY - 64;
        window.scrollTo({ top, behavior: 'smooth' });
      }
    }
  });
});

Authoring guidelines for agents

Read this if you're an AI agent building a doc with this kit.

  1. Tokens first. Never inline a hex code. Use var(--pink) etc. so projects can re-theme by swapping :root.
  2. One TL;DR per doc. First section. 30-second read. Hide everything else behind progressive disclosure.
  3. Cut text aggressively. If a paragraph can become a card, do it. If a list can become tiles, do it. If a wall of text can collapse into an accordion, collapse it.
  4. Color = meaning. Pink = now/urgent, Amber = soon/warning, Cyan = exploration, Lime = success/good signal, Red = stop/failure, Blue = ranked/structured, Grey = parked.
  5. Every interactive thing gets a stable data-id. Required for localStorage persistence to survive reload.
  6. No external dependencies. System fonts, inline CSS, vanilla JS. The whole file should open offline with zero requests.
  7. Mobile first. Every grid uses repeat(auto-fit, minmax(...)). Test at 360px.
  8. Voice. Direct. Specific. Take a position. No hedging. Quotes from the user appear in italic; the diagnostic appears in plain prose.
